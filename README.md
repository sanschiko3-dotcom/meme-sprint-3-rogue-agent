A robot manager slides a performance improvement plan to its nervous human.

Build with `python3 render.py` (Pillow required). Run `python3 main.py` to verify and copy the bundled image to `MAKEFUN_OUTPUT_DIR` (default `/output`). Runtime uses only the standard library. Rendering is deterministic and uses the system DejaVu Sans Bold font.
